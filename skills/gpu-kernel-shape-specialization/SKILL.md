# GPU 核函数特化

用于已有算子契约和共同起点的特化设计、实现或集成。一个主模型维护分支决策，可用同一模型配置的子 agent 并行研究机制、实现候选或审阅。受信工具提供编译、数值和测量证据。

仅获设计授权时，依据已有证据准备候选矩阵并标记待测。编译及设备实测按本项目授权执行。

## 输入与交付

- **输入**包括算子契约、目标及有序元数据、当前入口与保留配置、独立参考、实际环境和接纳政策。
- **设计交付**包括结构、现有路径、瓶颈证据及反例、竞争路线、守卫、合法参数和验证矩阵。
- **实现交付**包含带父版本的源码改动、运行时分派和后备、测试、实际测量入口及影响范围。
- **实测交付**逐版本报告搜索、配置选择、独立配对与局部决定。缺少阶段证据就记录待补项。

## 从结构到候选

1. 用独立参考及真实参数测共同起点。记录实际分支、工作分解、编译资源和完整入口。对可调起点取得有竞争力的保留配置。
2. 用等几何、等工作量等受控对照定位瓶颈。区分空任务、有效任务偏斜、尾块、访存、资源与入口准备。分别保存预测和观测。
3. 列竞争路线。说明改动位置、CTA 或线程的输出所有权、索引和 mask、归约与新增 workspace 或其他开销。覆盖尾块、空组、别名、索引边界和重排后的输出顺序。
4. 建立目标及候选矩阵。包含预期获益结构、边界、反例和合法未命中结构。每版本登记实际源码、原有限池、合法判据和独立确认。

## 守卫、缓存与扩域

| 决策 | 验证 |
|---|---|
| 精确匹配 | 绑定尺寸和有序长度、offsets、分页或索引。摘要索引后复核完整键或已验证的等价标识。 |
| 范围匹配 | 用运行时可取的结构特征和必要 dtype、layout、对齐与资源条件。验证域内反例、边界两侧、极值和顺序。 |
| 重叠及遮蔽 | 为精确键、范围和后备登记优先级，测试重叠规则实际命中的路径。 |
| 计划复用 | 说明生成、取得、复用、失效及主机/设备一致性。键覆盖影响运行和输出的条件，把计划和同步计入相应边界。 |
| 扩域 | 保留已有窄分支，以新输入的实际收益、边界、排列及资源证据决定是否扩大。 |

非法输入按契约处理，合法未命中走已登记的等价后备。记录实际命中覆盖。

## 实调、接纳和集成

把版本、结构、合法池、真实入口和参考交给实调。确认每个可接纳源码版本经过自己的搜索及独立配对确认。对同一目标用同一输入、设备和完整边界比较，按预登记条件接纳、保留、缩小守卫或回退。集成前后验证相同输入上的真实完整入口。复核受影响路径、共享依赖、后备及分派开销，再冻结代码和守卫交 T。T 的换参收益通过同一统一入口和同一批 T 输入比较 O 保留参数与 T 选中参数。
