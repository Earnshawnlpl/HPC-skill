# 比较组、消融与成本

## 1. 用对照回答论文的具体问题

| 对照 | 保持一致 | 变化和主要观察 |
|---|---|---|
| 主方法 vs 真实基线 | 算子契约、物理设备、实例、正确性、完整入口计时边界 | 比较预登记的默认/已调高性能库、共同起点、固定实现调参或其他实际对照。报告全套件正确性、时延、加速和回退 |
| 有模型 vs 去模型 | 共享经验快照、共同起点、LLM、修改权、Profile、实际参数搜索和停止政策 | 切换模型反馈与直接派生的动作。记录最终性能、失败、达标与耗用 |
| 有经验 vs 逐目标独立优化 | 共同起点、模型政策、编辑与验证权 | 切换来自其他目标的经验可见性。记录可比目标上的性能、成本和建库 |
| 固定实现 vs 结构检索实现 | 同一候选库和目标侧调参政策 | 固定组按登记规则指定实现。检索组依据当前结构选实现。记录配错、后备及检索开销 |
| 全池 vs 剪枝 | 合法池、模型、排序、目标及计时范围 | 切换准入后的实际暂缓。记录少测、恢复、审计、选中配置和实际费用 |

每对方法只改变与主张对应的因素。登记相同的机会、资源、停止或达标规则，并保留实际投入与结果。若需要量化模型和经验的交互，可为有/无模型与有/无经验分别登记配置，保持共同条件可比。

## 2. 该测哪些负载

- 主性能比较覆盖登记的整个目标分母。每种消融可用事先冻结的分层子集，同一对照共享目标，按工作几何、来源、结构长尾、边界特征与模型支持域报告覆盖。
- 样本范围由要支持的主张、统计不确定性和成本决定。扩充核心消融时，先锁定新增目标与分析法，按结构特征选择。保留旧、追加样本的身份和原因。
- 两组使用同一批 A 输入做直接配对。记录配对效果、正确性及失败。若估计整套件效果，遵循已登记抽样与权重，并分别展示分层结果。
- 把达到同一性能门槛的时间或 token 与最终性能分开。未达标的目标保留已花成本和观察终点。共享源码、基线或经验均登记被哪一组用过。

## 3. 记录实际成本和口径

| 项 | 怎么记 |
|---|---|
| 端到端总墙时 | 登记实际开始到报告交付的起止点。纳入该范围内的排队、等待、失败、重试与恢复 |
| 阶段费用 | 负载、参考/基线准备、构建、校准、O、集成、T、A 与交付的起止。将已记录活动的并集和尝试耗时分开 |
| 测量与设备 | 请求占用、队列等待、锁等待、实际占卡、编译、Profile、计算计时、独立确认与验证开销 |
| 模型 | 按会话或请求去重，记录模型、角色、输入、输出、缓存、耗时、重试、错误、未覆盖的 token。子 agent 成本归到对应方法和目标 |
| 公共准备 | 单列基线调优、建库与校准。报告每组目标侧增量和登记的摊销。共享开销按实际共同使用范围分配 |

阶段或请求时间可能重叠。总墙时用已登记的整体区间计算。已记活动取活动区间的并集，请求累计耗时独立记录。token 用量和价格使用各自的口径，缓存输入包含在总输入时只计一次。未知值保留未知状态。所有失败或退出也计入其已有账本。

## 4. 衡量选参和剪枝质量

- 保存登记的有限合法池和各状态。全池可比实测并确认后才使用池内最优。选择损失可计算为 `选中配置时延 ÷ 池内最佳时延 - 1`，两者计时范围一致。
- 报告搜索少测、影子拟剪、审计补测、恢复和剩余未测，分别统计支持域内外。把实际响应与预先规定的风险及撤销政策对照。
- 剪枝净成本在同范围全池真实对照下计算，包含描述、预测、搜索、审计及重试。校准共用时另给摊销口径。缺实际对照或关键开销时报告可确认的部分和缺口。

## 5. 交付核对

1. 提供可运行的统一入口与冻结参数、目标与生成依据、环境和强基线。
2. 保存每阶段的逐配置情况与逐负载验收，标出真实路径、结果阶段、正确性、后备与缺失。
3. 主结果与消融均能从汇总追到配对收据。表中标明阶段、单位、估计量、目标分母及计时范围。
4. 记录 token、请求、总墙时、阶段和建库/校准成本，附复现所需的实际命令或入口。标记运行过的范围和未完部分。
