# 实测、最终调参与独立验收

## 1. 预登记测量口径

在查看候选性能前登记环境、输入、正确性、计时范围、实际样本、统计和接纳政策。O、T、A 用可重建的共同接口与各自的数值实例或测量块。缺失的关键政策标记待定。

| 字段 | 具体做法 |
|---|---|
| 语义与精度 | 固定布局、索引/mask、输入输出类型、累加、特殊值、辅助输出及同步要求 |
| 正确性 | 使用独立参考，登记误差和容差，覆盖空任务、尾块、守卫边界、并发写入和最大合法条件 |
| 环境 | 记录物理设备、驱动、后端、编译器和运行时依赖。登记设备竞争、功耗策略或其他可能需要分层的变化 |
| 输入与资源 | 配对方法使用同值输入。登记状态还原、预分配、workspace、缓存、计划复用和首次 JIT 的政策 |
| 计时范围 | 设备 kernel、Graph 与完整调用分开。完整入口按实际路径纳入分派、计划、转换、分配、辅助计算及同步 |
| 统计 | 固定预热、交错或随机顺序、重复和实例数、重试、无效块、估计量、区间方法、最小实用收益与回退规则 |

主机时延用单调计时和对称同步，等待完整入口需要的异步工作结束。设备事件包住登记的流区间并核对跨流依赖。冻结实际复用条件，必要时分开报告冷、热场景。Profile 开销另记，持续的 profiler 观测与正常计时分开。

## 2. 执行并核验一个配对块

1. 用同一目标实例分别调用候选和基线，核对实际命中的分支、设备、配置与输入状态。
2. 校验输出结构、dtype、数值和输入变更。必要时用重复执行检查不稳定误差、未初始化缓冲和并发冲突。
3. 按登记规则预热和还原输入。把方法安排到同一个测量块内交错执行，保存实际顺序和同步边界。
4. 保存逐次时延、设备及正确性收据。发生漂移、外部任务或异常时按登记政策保留证据，做废或匹配重测有关块。
5. 按规定计算效果。例如对每个配对样本求 **基线时延 ÷ 候选时延**，再取配对比的中位数。选用 bootstrap 时保持配对块配对，并说明变异的层次。

独立确认采用与搜索分开的样本。跨数值实例、设备或计时范围的数值各有自己的用途与结果列。

## 3. O 阶段确认实现

每个版本真实搜索合法配置后，用独立块比较对同一目标的当前保留实现。检查输入、实际工作和完整调用。按登记的正确性、实用收益和不确定性政策做局部决定。保留 O 阶段的完整调用证据、选中分支和保留参数。实际退化、确认失败、未测和后备分别写入账本。

## 4. T 阶段选统一入口的参数

1. 冻结代码、边界语义、分派、guard、后备及合法参数域。把 O 保留配置接入同一个统一入口，保存可以直接复测的快照。
2. 在真实统一入口内测 T 配置。评估分支是否共享 workspace、调度、编译产物和参数，必要时同时改变及评估关联范围。
3. 搜索选中后，在**同一个统一入口、同一批 T 输入、同一计时范围**的独立配对块中比较 **O 保留参数与 T 选中参数**。保存两者的真实时延、正确性、配对效果和置信区间。
4. 施加预先登记的规则。要求稳定提升时，搜索最快项也需通过独立配对。持平、区间跨相应门槛、退化和失败按规则保留原参数或补证据。
5. 联合检查真正要交付的各路由及配置。集成有新代码、算法或守卫变更时，先重新完成受影响的 O 与集成验证。

O 原独立分支的时延和 T 的统一入口时延分列。统一入口内配对使用的 O 参数时延是评估换参收益的直接基线。

## 5. A 阶段给出正式结果

各方法及基线冻结后，由隔离的评估步骤取 A 实例和参考。先检查语义和数值，再按登记的完整入口边界执行配对计时。输出每个目标的方法、实际路径、配置、时延、正确性、配对效果、测量状态与成本依据。

| 结果状态 | 对外口径 |
|---|---|
| 可比较 | 有相同边界、有效正确性和独立计时，保留效应量与统计不确定性 |
| 性能退化或持平 | 保留真实时延、区间和接纳状态 |
| 后备 | 记录实际调用和成本，在目标分母中识别专用、通用及失败 |
| 数值失败、缺失或无效计时 | 记录真实状态与原因，无法计算的值留空 |
| 未见结构 | 明确留出域、覆盖和后备，单独给出泛化证据 |

总体效果用逐负载数据聚合，报告登记分母、可比覆盖、失败比例、实际权重和分层结果。按登记口径报告中位数或几何均值。配对计时的重复样本保留块结构，跨负载的同源派生按抽样分组。A 反馈用于后续开发时，建立新的优化身份与独立验收。配对比较与成本报告见[实验比较与成本](ablation-and-cost.md)。
