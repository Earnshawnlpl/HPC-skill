# 最终调参、验收与成本

## T 与 A

先冻结统一入口、算法分支、守卫和合法配置域。T 在实际统一入口上为每个负载搜索这些允许的参数，保存试验、选择、正确性和独立复测。

要量化最终调参的增益，在同一统一入口、同一批 T 数值实例及交错次序内配对测量 **O 保留参数** 与 **T 选中参数**。预先登记差异不确定或出现退化时的参数保留政策。单分支 O 复测和统一入口 T 复测各自保留其计时范围。最终联合检查所有分派和参数后，冻结唯一交付。

A 在所有比较方案冻结后运行。独立评估实现逐负载正确性、完整入口时延、配对加速比及统计区间。报告各目标的失败、后备、缺失和达标状态。验收结果留在本轮评估账本，需要据此修改代码时启动新的优化身份与独立验收。

## 按论文结论选择消融

| 消融 | 两组保持一致的主体与单独改变的因素 |
|---|---|
| 有模型与去模型 | 匹配经验库、共同起点、主模型、编辑权限、测量反馈、搜索与停止政策。切换可见的硬件模型反馈和由它直接派生的决策。 |
| 经验复用与逐目标独立优化 | 匹配模型和验证政策。切换从其他目标检索和复用已验证经验的权限。分别报告目标增量及建库成本。 |
| 固定库实现与结构检索实现 | 匹配冻结库和逐目标调参。固定组按事先登记的规则选定实现，检索组依据输入结构选择已有实现。 |
| 模型排序与正式剪枝 | 匹配模型、候选池与排序。独立比较全池实测、实际少测、审计、撤销和选择质量。 |

主性能比较覆盖预先登记的套件。消融可采用提前冻结的分层子集，同一对照使用同一批目标。核心结论需要对应的覆盖与直接配对证据。报告分层结果，并说明全套件估计的权重。对相近的结果保留不确定性，同时记录成功率、token、达到同一性能阈值所需成本和未达标的已耗成本。

## 成本账本和报告

| 记录层级 | 应包含的口径 |
|---|---|
| 整轮 | 明确起点和报告落盘终点。端到端总墙时包含范围内等待、失败与恢复，续跑继承时间起点。 |
| 阶段与目标 | 记录尝试起止、已记活动、GPU 等待和占用、编译、Profile、搜索、独立复测与失败。活动有重叠时用时间并集。 |
| 模型 | 按可核对的会话或请求去重记录输入、输出、缓存、请求耗时、错误和重试。标记未知用量。子 agent 成本归入其所属任务。 |
| 可共享准备 | 单列建库、硬件校准与公共基线，报告各方法目标端增量以及可解释的摊销口径。 |
| 剪枝 | 记录原合法池、真实暂缓、影子拟剪、审计补测、选择损失及费用。净节省以同范围的全池实际成本为对照，计入模型、核验、审计和重试。 |

交付冻结的入口及配置、目标清单、基线版本、计时政策、逐目标结果和可审计成本。表格按 O、T、A 明确阶段，在摘要中提供效果与正确性，保留用于复现的逐目标明细。用项目实际支持的工具生成和核验收据。
