# 分支优化、模型与实际搜索

## 路线与经验

先做共同起点的正确性检查、必要调参和实测，辨认当前结构最可能受限的阶段。针对机制建立若干竞争路线，例如映射与负载平衡、tile、并行归约、访存、流水、稀疏或变长调度。为路线记录适用条件、合法参数、预期受益来源、额外开销及可反驳的观测。

| 可拆分任务 | 交付 |
|---|---|
| 研究 | 可追溯的论文和源码、许可证、机制、反例 |
| 分析 | 当前分支的受信描述、成本或观测、未知项与验证假设 |
| 实现 | 绑定目标与父版本的补丁、合法配置域和回归范围 |
| 审阅 | 对契约、正确性风险、守卫及证据的检查 |

主模型可以亲自完成这些任务，或按依赖并行委派给同一模型配置的子 agent。按角色给出最小所需材料，隔离候选修改与独立验收。编译、Profile 和计时由受信工具产生收据，主模型核对后才用于决策。

经验记录来源目标、结构特征、代码和参数空间、适用边界、测量范围、失败和开销。每个目标开工前绑定可见的经验快照。可以先检索适用的已有实现并为当前目标实调，也可以改写或提出新路线。跨算子或环境优先迁移机制假设，再取得新证据。消融组之间共享预先登记的公共材料，各自的局部反馈保持隔离。

## 建立与使用分支成本

分析单位是当前结构实际命中的分支和配置。绑定结构、源码摘要、依赖、合法池、编译器与硬件、算子契约、模型版本和计时范围。用源代码、编译输出和观测交叉校验执行描述。

| 组件 | 对应证据 |
|---|---|
| 计算 | 指令或 tile 工作、数据类型、吞吐响应、尾部利用率 |
| 访存 | 真实字节、访问模式、缓存与内存服务、共享内存 |
| 资源 | 寄存器、共享内存、占用率、溢出与竞争 |
| 调度与组合 | CTA 分布、异质任务尾部、同步、阶段依赖及有证据的重叠 |

共享组件在对应输入和环境有效域内校准。用分支执行图表述组件组合，区分串行、关键路径、重叠及共享开销。把待测偏差作为模型不确定性。计入命中的前后处理，互斥分支按实际执行路径计价。

先封存运行前预测，再收集当前候选实测。无独立验证或目标超出支持域时，用有依据的部分排序并保留未知项的探索资格。正式模型剪枝需事先固定风险门槛、保留与探索、独立验证、审计与撤销政策，并核对当前范围的准入。用 GPU 阶段的模型只决策相应阶段。

## 每个新候选的测量与收敛

1. 绑定目标、父版本、实际源码和完整有限合法池。区分源码修改与同一源码内允许的参数变化。
2. 运行静态检查和正确性检查，再按政策真实调参。初次配置失败时保留失败证据，继续覆盖有依据的替代项。
3. 原池保留合法、非法、已测、失败、暂缓和未完成状态。通过准入的剪枝可撤销，未测项留有审计记录。默认用实际搜索完成政策，另报原池是否穷尽。
4. 对所选配置做独立完整入口复测，按同目标的正确性与收益政策局部接纳。新代码、重排、预处理和分派的开销都进入同一计时边界。
5. 集成后验证运行时守卫、共享依赖和实际受影响的目标。超出覆盖域的合法输入走契约匹配的后备。失败与后备命中保留在固定分母。
6. 以登记的收敛、资源或停止政策结束路线。规则和经验从可复用机制中提炼，保存实验条件与反例。完成阶段的状态和性能达标分别记录。
