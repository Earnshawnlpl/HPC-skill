# 工作负载、参考与基线

## 1. 登记算子和实验边界

| 字段 | 需要固定的内容 |
|---|---|
| 契约 | 输入输出结构、dtype、累加精度、布局、stride、设备与内存别名、mask 与索引语义、特殊值、空任务、辅助输出及可修改输入 |
| 数值参考 | 能独立复核的实现或明确公式、生成配方、逐输出误差指标和接受容差 |
| 实际入口 | 用户调用怎样取得元数据、分配与复用 workspace、计划构建、异步执行、同步、前后处理及后备 |
| 支持域 | 负载形状与分布、索引与资源上界、合法配置、失败分类，稳定输入和变化输入的复用预期 |
| 实验设计 | 目标、比较方法和观察量、结构或来源抽样、权重、运行与停止政策、阶段数据可见性 |

对每个研究问题写清分析单位。例如“已知 expert 分组结构的专用实现”以有序分组为单位，“未见结构泛化”以额外结构或来源留出为单位。相关设定从本课题读取，实际入口缺失时先交付范围及验证缺口。

## 2. 构建可解释的负载集合

1. **确定结构身份。** 用算子契约和实际影响执行组织的有序长度、offsets、分页、稀疏索引和布局等字段生成结构键。值 seed 或重复测量沿用原结构键。
2. **真实来源。** 保存来源版本、记录或采样标识、采样窗口、允许使用条件和转换脚本。记录原工作几何与数量变化。从真实结构生成随机张量时标记为结构回放。
3. **控制变量。** 先定义每对或每族样本的不变量，再验实际产物。示例是固定 MoE 的 N/K、expert 数及总 token，改变每个 expert 的长度和顺序。Attention 里等 token 和等有效交互属于两种控制设计。
4. **压力与反例。** 按机制生成空分支、尾块、长短混合、索引离散、边界资源、混合精度允许的极值，以及相似摘要但不同有序结构的成对用例。
5. **评价覆盖。** 按实际量绘制或统计规模、形状、分布、偏斜、边界和来源覆盖。回放同一结构、修改标签或增加重复数沿用原目标计数。来源和配对关系一同登记。
6. **重建与检验。** 核对数学参考、合法性、资源、输入出处和可重建摘要，编译和实测前做小批次流水线冒烟。非法输入、合法但后端不支持、参考错误和用例未测各自留记录。
7. **冻结。** 达到已声明的覆盖和可执行条件后锁定结构、顺序、目标分母、权重、指标及初始方案。若需新加任务，登记新批次及与原批次的关系。

| 机制 | 控制样本可以怎么构建 |
|---|---|
| 成组 GEMM | 同 N/K 与总 M，改变每组 M、活跃组数、尾块和排序，保持组与权重的对应 |
| Paged Decode | 固定有效 KV 数和注意力语义，改变页局部性、请求长度分布、有效末页和 batch 组成 |
| 稀疏访问 | 固定实际有效索引数，改变局部性、重复或顺序，重复及顺序仅在契约允许时变化 |
| Ragged Prefill | 记录各请求 Q/KV、mask 和真实交互数，在合适的条件下分别控制总 token 或有效工作量 |

## 3. 结构、数值和阶段隔离

| 边界 | 具体操作 |
|---|---|
| 已知结构特化 | O 可用结构及开发输入，T 用冻结结构重建选参和确认块，A 用隔离数值或测量块，结构身份贯通 |
| 未见结构或来源泛化 | 设计阶段按实体、结构或可复现的生成分区留出，相关派生按谱系成组处理 |
| 模型估计与剪枝 | 组件拟合、置信区间或门槛校准、独立准入评估使用独立登记样本 |
| 消融 | 共享已声明的公共参考、起点及经验库快照，各方法的局部反馈在自己的运行范围内使用 |

同一负载在不同阶段的张量值可以不同。一次配对测量内，参与比较的各方用相同的输入和状态还原规则。独立验收输入、答案和结果用单独权限或评估器持有。

## 4. 接通共同起点和真实基线

| 角色 | 实作和应交付的证据 |
|---|---|
| 独立数学参考 | 固定每个输出的语义与计算精度，用直接实现或可信的高精度实现，输出误差摘要和错例 |
| 共同起点 | 一份合法完整入口和可审查参数池。实测初始调参并独立确认配置，结果用于 O 比较和后备 |
| 高性能库默认 | 用项目选定版本的真实高性能后端。保存调用签名、后端选择、实际默认 tactic、计划和 workspace 行为 |
| 高性能库调优 | 用库支持的公开接口枚举或登记有限配置，逐目标实测、独立确认选中项，保存池摘要与默认保留记录 |
| 固定实现与自动调参 | 同一源码和语义，分别绑定预设参数和合法池实测选出的参数 |
| 有限空间 Oracle | 穷尽已登记原池的全部合法项并确认最佳可执行项，记录池边界、完整成本和失败。用于检查选择质量 |

首次测量先用一个代表目标确认编译、输入一致性、所有输出和基线真实后端。再覆盖各资源与语义边界。使用项目实际可得的基线，高性能库和数学参考可以由同一库承担但分别绑定精度、调用方式和性能用途。

默认和已调配置，以及设备计时和完整入口计时各有各的列。完整入口按实际需要计入分派、计划、转换、分配、workspace、启动、同步与归并。报告模板和统计见[计时与验收](acceptance-and-cost.md)。
